# RT-DETR 自动处理服务 - 使用指南

## 📦 安装

```bash
cd /home/ubuntu/lsn/project_new/RT-DETR-main/A_sclie2inference/DataSlice2Inference_main

# 1. 安装Python依赖
pip install -r requirements.txt

# 2. 配置参数（编辑 config.yaml）
nano config.yaml
# 主要配置项：
#   - paths.watch_dir: 监听目录（大图存放位置）
#   - paths.output_dir: 输出目录（推理结果存放位置）
#   - paths.model_path: 模型文件路径
#   - processing.threshold: 置信度阈值（0.5表示50%）

# 3. 安装systemd服务（可选，用于后台运行）
./service_manager.sh install
```

## 🚀 启动服务

### 方式1：直接启动（推荐，可看到实时日志）
```bash
python service_main.py
```

### 方式2：后台运行
```bash
nohup python service_main.py > service.log 2>&1 &
```

### 方式3：使用systemd服务（需先安装）
```bash
./service_manager.sh start
# 或
sudo systemctl start rtdetr-processor
```

## 🛑 停止服务

### 方式1：Ctrl+C（前台运行时）
直接按 `Ctrl+C`，1-2秒内会优雅关闭

### 方式2：使用管理脚本
```bash
./service_manager.sh stop
```

### 方式3：systemd命令
```bash
sudo systemctl stop rtdetr-processor
```

### 方式4：查找并终止进程
```bash
ps aux | grep service_main.py
kill -SIGINT <PID>
```

## 📊 查看状态和日志

```bash
# 查看服务状态
./service_manager.sh status
# 或
sudo systemctl status rtdetr-processor

# 查看日志（最近100行）
./service_manager.sh logs

# 实时查看日志
./service_manager.sh logs -f
# 或
sudo journalctl -u rtdetr-processor -f

# 健康检查（需在config.yaml中启用monitoring.health_check_port）
curl http://localhost:8081/health
curl http://localhost:8081/stats
```

## 🔄 重启服务

```bash
./service_manager.sh restart
# 或
sudo systemctl restart rtdetr-processor
```

## 🎨 全图可视化生成

根据批量推理结果生成全图可视化：

```bash
cd /home/ubuntu/lsn/project_new/RT-DETR-main/A_sclie2inference/DataSlice2Inference_main

# 基本用法（自动从annotations.json读取大图路径）
python global_visualizer/visualize_global_annotations.py \
  --annotations /path/to/annotations.json

# 指定大图路径
python global_visualizer/visualize_global_annotations.py \
  --annotations /path/to/annotations.json \
  --image /path/to/original_image.jpeg

# 指定输出路径
python global_visualizer/visualize_global_annotations.py \
  --annotations /path/to/annotations.json \
  --output /path/to/output_visualization.png

# 只显示置信度>0.5的检测框
python global_visualizer/visualize_global_annotations.py \
  --annotations /path/to/annotations.json \
  --score-threshold 0.5

# 只显示指定类别（如只显示"SQ"和"LC"）
python global_visualizer/visualize_global_annotations.py \
  --annotations /path/to/annotations.json \
  --class-filter SQ LC

# 隐藏标签（只绘制框，不显示文字）
python global_visualizer/visualize_global_annotations.py \
  --annotations /path/to/annotations.json \
  --hide-label
```

## 🗑️ 手动清除处理记录

清除已处理记录，使文件可以重新处理：

```bash
cd /home/ubuntu/lsn/project_new/RT-DETR-main/A_sclie2inference/DataSlice2Inference_main

# 清除单个文件记录
python utils/clear_processed_record.py --image /path/to/image.jpeg

# 预览模式（不实际删除，仅查看）
python utils/clear_processed_record.py --image /path/to/image.jpeg --dry-run

# 清除整个目录的记录
python utils/clear_processed_record.py --dir /path/to/images/

# 批量清除多个文件
python utils/clear_processed_record.py --images /path/to/img1.jpeg /path/to/img2.jpeg

# 从文件列表清除（每行一个路径）
python utils/clear_processed_record.py --list /path/to/file_list.txt

# 清除所有记录（危险操作，需确认）
python utils/clear_processed_record.py --clear-all

# 查看详细调试信息
python utils/clear_processed_record.py --image /path/to/image.jpeg --debug
```

## 🔧 批量推理（手动）

手动对patch目录进行批量推理：

```bash
cd /home/ubuntu/lsn/project_new/RT-DETR-main/A_sclie2inference/DataSlice2Inference_main

# 基本用法（使用config.yaml中的配置）
python inferenceTool/predict_batch_torchscript.py \
  --patch-dir /path/to/patches \
  --global-image-url /path/to/original_image.jpeg

# 指定模型路径
python inferenceTool/predict_batch_torchscript.py \
  --patch-dir /path/to/patches \
  --model /path/to/model.pt

# 自定义参数（覆盖配置文件）
python inferenceTool/predict_batch_torchscript.py \
  --patch-dir /path/to/patches \
  --threshold 0.3 \
  --batch-size 32 \
  --device cuda:1 \
  --no-visualization

# 使用自定义配置文件
python inferenceTool/predict_batch_torchscript.py \
  --config /path/to/custom_config.yaml \
  --patch-dir /path/to/patches
```

## ⚙️ 配置文件说明

主要配置文件：`config.yaml`

### 关键配置项

```yaml
paths:
  watch_dir: "/path/to/watch"      # 监听目录
  output_dir: "/path/to/output"    # 输出目录
  model_path: "/path/to/model.pt"   # 模型路径

processing:
  threshold: 0.5                   # 置信度阈值
  max_concurrent_tasks: 2          # 最大并发任务数

batch_inference:                   # 批量推理配置
  device: "auto"                   # 设备（auto/cpu/cuda）
  use_fp16: true                   # FP16加速
  threshold: 0.5                   # 置信度阈值
  batch_size: null                 # 批量大小（null=自动）
  save_visualization: true         # 保存可视化图片
```

## 🔍 故障排查

### 服务启动失败
```bash
# 检查服务是否已安装
./service_manager.sh status

# 如果未安装，先安装
./service_manager.sh install

# 查看详细错误
./service_manager.sh logs
```

### 文件未被处理
```bash
# 检查文件是否已在处理记录中
cat processing_status.json | grep "your_file_name"

# 清除记录后重新处理
python utils/clear_processed_record.py --image /path/to/image.jpeg
touch /path/to/image.jpeg  # 触发文件事件
```

### GPU显存不足
```bash
# 在config.yaml中减小batch_size
# 或使用命令行参数
python inferenceTool/predict_batch_torchscript.py \
  --patch-dir /path/to/patches \
  --batch-size 8  # 减小批量大小
```

### 查看详细日志
```bash
# 实时日志
tail -f logs/auto_processor_*.log

# systemd日志
sudo journalctl -u rtdetr-processor -f
```

## 💡 提示

- **首次使用**：建议先用 `start-direct` 模式测试，确认无误后再使用systemd服务
- **批量推理**：大批量时建议关闭可视化（`--no-visualization`）以提升速度
- **GPU优化**：启用FP16可提升40%速度，减少50%显存占用
- **并发处理**：根据GPU显存调整 `max_concurrent_tasks` 和 `batch_size`
- **日志管理**：日志文件会自动轮转，可在config.yaml中配置大小和数量
