# RT-DETR 快速参考

## 🚀 启动

```bash
cd /home/ubuntu/lsn/project_new/RT-DETR-main/A_sclie2inference/DataSlice2Inference_main

# 直接启动（推荐）
python service_main.py

# 后台运行
nohup python service_main.py > service.log 2>&1 &

# systemd服务（需先安装）
./service_manager.sh install  # 首次使用
./service_manager.sh start
```

## 🛑 停止

```bash
# Ctrl+C（前台运行时）
# 或
./service_manager.sh stop
sudo systemctl stop rtdetr-processor
```

## 📊 查看状态

```bash
./service_manager.sh status
./service_manager.sh logs -f  # 实时日志
curl http://localhost:8081/health  # 健康检查
```

## 🎨 全图可视化

```bash
python global_visualizer/visualize_global_annotations.py \
  --annotations /path/to/annotations.json \
  --score-threshold 0.5
```

## 🗑️ 清除记录

```bash
# 清除单个文件
python utils/clear_processed_record.py --image /path/to/image.jpeg

# 清除目录
python utils/clear_processed_record.py --dir /path/to/images/

# 预览模式
python utils/clear_processed_record.py --image /path/to/image.jpeg --dry-run
```

## 🔧 批量推理

```bash
python inferenceTool/predict_batch_torchscript.py \
  --patch-dir /path/to/patches \
  --global-image-url /path/to/original_image.jpeg \
  --threshold 0.5
```

## ⚙️ 配置

编辑 `config.yaml`：
- `paths.watch_dir`: 监听目录
- `paths.model_path`: 模型路径
- `processing.threshold`: 置信度阈值
- `batch_inference.batch_size`: 批量大小（null=自动）

## 📁 目录

- 监听目录: `${WATCH_DIR}` (默认: `../DataWSI`)
- 输出目录: `${OUTPUT_DIR}` (默认: `../DataPatchesInference`)
- 日志目录: `./logs/`
- 状态文件: `./processing_status.json`
