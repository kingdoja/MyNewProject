# RT-DETR 快速参考指南

## 🚀 快速启动

```bash
cd /home/ubuntu/lsn/project_new/RT-DETR-main/A_sclie2inference/DataSlice2Inference_main

# 启动服务（前台运行，可看实时日志）
python service_main.py

# 或后台运行
nohup python service_main.py > service.log 2>&1 &
```

## ⏹️ 停止服务

```bash
# 方式1: Ctrl+C（现在可以正常响应了！）
# 按一次：优雅停止（1-2秒）
# 按两次：强制退出

# 方式2: 使用脚本
./service_manager.sh stop
```

## 🔄 重新处理已处理的文件

```bash
# 步骤1: 清除记录
python utils/clear_processed_record.py --image ../DataWSI/example.jpeg

# 步骤2: 触发重新处理
touch ../DataWSI/example.jpeg
```

## ⚙️ 关键配置

```yaml
# config.yaml
processing:
  file_wait_timeout: 15  # 文件等待时间
  max_concurrent_tasks: 2  # 并发数（1-4）
  
filtering:
  auto_bg: true  # 自动背景分析（推荐）
```
