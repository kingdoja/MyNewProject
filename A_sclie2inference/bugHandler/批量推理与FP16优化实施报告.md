### 优化2: FP16混合精度 ⚡⚡

#### 2.1 模型FP16转换

```python
def load_torchscript_model(model_path: str, device: torch.device, use_fp16: bool = True):
    """加载模型并启用FP16"""
    model = torch.jit.load(model_path, map_location=device)
    model.eval()
    
    # 启用FP16（仅GPU支持）
    if use_fp16 and device.type == 'cuda':
        model = model.half()  # ✨ 关键一行！
        print("✅ 已启用 FP16 混合精度加速")
        print("   - 推理速度提升约40%")
        print("   - 显存占用减少约50%")
    
    return model
```

#### 2.2 输入数据FP16转换

```python
def prepare_image(image_path: str, device: torch.device, use_fp16: bool = False):
    """加载图像并转换为FP16"""
    image_tensor = transforms(image_pil).unsqueeze(0).to(device)
    
    # 如果使用FP16，转换数据类型
    if use_fp16 and device.type == 'cuda':
        image_tensor = image_tensor.half()  # FP32 → FP16
    
    return image_pil, image_tensor, orig_sizes
```

## 📝 技术细节

### FP16工作原理

**FP32 (单精度)**:
- 32位浮点数
- 精度: ~7位有效数字
- 范围: ±3.4×10³⁸

**FP16 (半精度)**:
- 16位浮点数
- 精度: ~3位有效数字
- 范围: ±65504

**为什么FP16更快？**
1. 数据传输量减半（显存↔GPU核心）
2. 计算吞吐量提升（Tensor Core加速）
3. 显存占用减半（可用更大batch size）

**精度影响**:
- 深度学习对精度要求不高
- FP16误差通常<1%
- 目标检测任务几乎无影响

### 批量推理原理

**为什么批量更快？**

1. **GPU并行计算**
   ```
   单张: [      GPU 10%      ][等待90%]
   批量: [      GPU 80%      ][等待20%]
   ```

2. **减少kernel启动开销**
   ```
   单张: 启动-计算-启动-计算-...（开销大）
   批量: 启动-批量计算-完成（开销小）
   ```

3. **内存访问优化**
   ```
   单张: 频繁的数据传输
   批量: 一次传输多张图
   ```
