# RT-DETR 模型导出为.pt格式 - 使用说明

## 📋 概述

本文档说明如何将训练好的RT-DETR模型导出为PyTorch的`.pt`格式。项目提供了两个导出脚本：
- `rtdetr_pytorch/tools/export_pt.py` - RT-DETR v1版本
- `rtdetrv2_pytorch/tools/export_pt.py` - RT-DETR v2版本

## 🚀 快速开始

### 基本用法（推荐）

最简单的导出方式是只导出模型权重（state_dict），体积小，加载快：

```bash
# RT-DETR v1
cd rtdetr_pytorch
python tools/export_pt.py \
    --config configs/rtdetr/rtdetr_r18vd_6x_coco.yml \
    --resume output/best.pth \
    --mode state_dict

# RT-DETR v2
cd rtdetrv2_pytorch
python tools/export_pt.py \
    --config configs/rtdetrv2/rtdetrv2_r18vd.yml \
    --resume output/best.pth \
    --mode state_dict
```

## 📖 导出模式说明

脚本支持4种导出模式：

### 1. state_dict（推荐）⭐

**特点：**
- 只保存模型权重，不保存模型结构
- 文件体积最小
- 需要配合模型定义代码使用
- 最灵活，便于代码修改

**使用方法：**
```bash
python tools/export_pt.py \
    --config configs/your_config.yml \
    --resume checkpoints/best.pth \
    --mode state_dict \
    --output model_weights.pt
```

**加载方式：**
```python
import torch
from src.core import YAMLConfig

# 构建模型
cfg = YAMLConfig('configs/your_config.yml')
model = cfg.model

# 加载权重
state_dict = torch.load('model_weights.pt')
model.load_state_dict(state_dict)
model.eval()
```

### 2. full_model

**特点：**
- 保存完整模型（结构 + 权重）
- 文件体积较大
- 加载时不需要模型定义代码
- 但模型结构被固化，不够灵活

**使用方法：**
```bash
python tools/export_pt.py \
    --config configs/your_config.yml \
    --resume checkpoints/best.pth \
    --mode full_model \
    --output model_full.pt
```

**加载方式：**
```python
import torch

# 直接加载完整模型
model = torch.load('model_full.pt')
model.eval()
```

### 3. torchscript

**特点：**
- 导出为TorchScript格式
- 可以在C++环境中使用
- 适合生产部署
- 包含模型和后处理
- 性能优化

**使用方法：**
```bash
python tools/export_pt.py \
    --config configs/your_config.yml \
    --resume checkpoints/best.pth \
    --mode torchscript \
    --input-size 640 \
    --output model_torchscript.pt
```

**加载方式：**
```python
import torch

# 加载TorchScript模型
model = torch.jit.load('model_torchscript.pt')
model.eval()

# 推理
images = torch.rand(1, 3, 640, 640)
sizes = torch.tensor([[640, 640]])
outputs = model(images, sizes)
```

### 4. deploy

**特点：**
- 导出部署就绪的模型
- 包含后处理步骤
- 输入图像直接输出检测结果
- 便于直接部署使用

**使用方法：**
```bash
python tools/export_pt.py \
    --config configs/your_config.yml \
    --resume checkpoints/best.pth \
    --mode deploy \
    --output model_deploy.pt
```

**加载方式：**
```python
import torch

# 加载部署模型
model = torch.load('model_deploy.pt')
model.eval()

# 推理
images = torch.rand(1, 3, 640, 640)
sizes = torch.tensor([[640, 640]])
outputs = model(images, sizes)
# outputs包含: labels, boxes, scores
```

## 📝 完整参数说明

```bash
python tools/export_pt.py \
    --config CONFIG_FILE \      # 必需: 配置文件路径
    --resume CHECKPOINT_PATH \  # 必需: checkpoint文件路径
    --mode MODE \              # 可选: 导出模式 (默认: state_dict)
    --output OUTPUT_FILE \     # 可选: 输出文件路径 (默认: 自动生成)
    --input-size SIZE          # 可选: 输入尺寸 (仅torchscript模式, 默认: 640)
```

### 参数详解

| 参数 | 说明 | 是否必需 | 默认值 |
|------|------|----------|--------|
| `--config` / `-c` | 训练时使用的配置文件路径 | 是 | - |
| `--resume` / `-r` | 训练好的checkpoint文件路径 | 是 | - |
| `--mode` / `-m` | 导出模式：state_dict / full_model / torchscript / deploy | 否 | state_dict |
| `--output` / `-o` | 输出文件路径 | 否 | 自动生成 |
| `--input-size` | TorchScript模式的输入图像尺寸 | 否 | 640 |

## 🔍 checkpoint文件说明

训练过程中，模型会保存为checkpoint文件（通常是`.pth`格式），包含：
- `model`: 模型权重
- `ema`: EMA（指数移动平均）模型权重（如果启用）
- `optimizer`: 优化器状态
- `epoch`: 训练轮数
- 其他训练状态信息

导出脚本会：
1. 优先使用EMA权重（如果有）
2. 否则使用标准模型权重

## ❓ 常见问题

### Q1: 导出的.pt文件和训练的.pth文件有什么区别？

- `.pth`文件：训练checkpoint，包含完整训练状态（模型、优化器、epoch等）
- `.pt`文件：导出的模型文件，通常只包含推理所需内容

### Q2: 选择哪种导出模式？

- **日常使用/继续训练**：使用`state_dict`
- **快速部署Python环境**：使用`deploy`
- **C++/移动端部署**：使用`torchscript`
- **不想处理配置文件**：使用`full_model`

### Q3: 导出后文件很大怎么办？

1. 使用`state_dict`模式（最小）
2. 确认不需要的组件已移除
3. 考虑模型量化（需要额外步骤）

### Q4: EMA权重和标准权重有什么区别？

EMA（指数移动平均）权重通常训练更稳定，泛化性能更好，推荐优先使用。

### Q5: 如何验证导出的模型是否正确？

```python
import torch

# 加载模型
model = torch.load('your_model.pt')  # 或用相应的加载方式
model.eval()

# 创建测试输入
test_input = torch.rand(1, 3, 640, 640)
test_size = torch.tensor([[640, 640]])

# 测试推理
with torch.no_grad():
    output = model(test_input, test_size)
    print(f"输出形状: {output}")
```
