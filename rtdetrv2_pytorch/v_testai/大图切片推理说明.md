# RT-DETR 大图切片推理说明

## 一、模型推理时标注框生成流程

### 1. 推理流程概述

```
输入图像 → 预处理 → 模型推理 → 后处理 → 输出标注框
```

### 2. 详细步骤

#### 步骤1: 图像预处理
**代码位置**: `inference.py` 第59-65行

```python
# 图片预处理
transforms = T.Compose([
    T.Resize((640, 640)),  # 将图像resize到640x640
    T.ToTensor(),          # 转换为tensor
])

image_tensor = transforms(image_pil).unsqueeze(0).to(device)
orig_size_tensor = torch.tensor([[original_size[0], original_size[1]]], dtype=torch.int64, device=device)
```

**关键点**:
- 输入图像被resize到固定大小(640x640)
- 保存原始图像尺寸信息(`orig_size_tensor`)用于后续坐标还原

#### 步骤2: 模型前向推理
**代码位置**: `inference.py` 第43-46行

```python
def forward(self, images, orig_target_sizes):
    outputs = self.model(images)  # 模型推理，输出logits和boxes
    outputs = self.postprocessor(outputs, orig_target_sizes)  # 后处理
    return outputs
```

**模型输出**:
- `pred_logits`: 预测的类别置信度 [batch, num_queries, num_classes]
- `pred_boxes`: 预测的边界框坐标 [batch, num_queries, 4] (格式: cxcywh)

#### 步骤3: 后处理（核心）
**代码位置**: `src/zoo/rtdetr/rtdetr_postprocessor.py` 第48-87行

这是**标注框生成的核心代码**！

```python
def forward(self, outputs, orig_target_sizes):
    logits, boxes = outputs['pred_logits'], outputs['pred_boxes']
    
    # 1. 坐标格式转换: cxcywh -> xyxy
    bbox_pred = torchvision.ops.box_convert(boxes, in_fmt='cxcywh', out_fmt='xyxy')
    
    # 2. 坐标还原到原始图像尺寸 (这是关键!)
    bbox_pred *= orig_target_sizes.repeat(1, 2).unsqueeze(1)
    
    # 3. 计算置信度分数
    if self.use_focal_loss:
        scores = F.sigmoid(logits)
        # 选择top-k个检测结果
        scores, index = torch.topk(scores.flatten(1), self.num_top_queries, dim=-1)
        labels = index % self.num_classes
        index = index // self.num_classes
        boxes = bbox_pred.gather(dim=1, index=index.unsqueeze(-1).repeat(1, 1, bbox_pred.shape[-1]))
    
    # 4. 返回标注框
    if self.deploy_mode:
        return labels, boxes, scores  # labels: 类别ID, boxes: xyxy坐标, scores: 置信度
```

**坐标转换详解**:
```python
# 假设原始图像尺寸为 (800, 600)
# orig_target_sizes = [[800, 600]]

# 模型输出的boxes是归一化坐标 (0-1之间)
# bbox_pred的格式是 [x1, y1, x2, y2]，每个值在0-1之间

# 坐标还原公式:
# x1_pixel = x1_normalized * original_width
# y1_pixel = y1_normalized * original_height
# x2_pixel = x2_normalized * original_width
# y2_pixel = y2_normalized * original_height

# 代码实现:
bbox_pred *= orig_target_sizes.repeat(1, 2).unsqueeze(1)
# orig_target_sizes.repeat(1, 2) = [[800, 600, 800, 600]]
```

### 3. 最终输出格式

```python
labels: Tensor[N]  # 类别ID (0, 1, 2, ...)
boxes: Tensor[N, 4]  # 边界框坐标 [x1, y1, x2, y2]，单位：像素
scores: Tensor[N]  # 置信度分数 (0-1之间)
```

**坐标系统**:
- x1, y1: 左上角坐标（像素）
- x2, y2: 右下角坐标（像素）
- 坐标相对于**原始输入图像**的尺寸

## 二、小图坐标转换为大图坐标

### 问题场景

1. 有一个大图（ndpi格式），尺寸如 10000x8000
2. 切分成640x640的小图进行训练和推理
3. 模型输出的坐标是基于小图的（0-640范围）
4. 需要将坐标转换回大图坐标系统

### 解决方案

#### 方法1: 记录切片位置信息

在切片时保存每个小图的位置信息（您已经这样做了！）

```python
# 您的切片代码已经保存了坐标信息
writer.writerow([
    patch_count,
    filename,
    x, y,           # 小图在大图中的起始位置
    x_end, y_end,
    x_end - x, y_end - y
])
```

#### 方法2: 坐标转换公式

```python
# 小图坐标 -> 大图坐标
大图_x1 = 小图_x1 + 切片起始位置_x
大图_y1 = 小图_y1 + 切片起始位置_y
大图_x2 = 小图_x2 + 切片起始位置_x
大图_y2 = 小图_y2 + 切片起始位置_y
```

## 五、常见问题

### Q1: 为什么模型输出的坐标已经是原始图像尺寸了？
A: 因为后处理器中有这行代码：
```python
bbox_pred *= orig_target_sizes.repeat(1, 2).unsqueeze(1)
```
这会将归一化坐标(0-1)转换为实际像素坐标。

### Q2: 坐标格式是什么？
A: xyxy格式，即 [x1, y1, x2, y2]，左上角和右下角坐标。

### Q3: 如何提高大图检测准确性？
A: 
1. 增加切片重叠区域（overlap）
2. 使用NMS去除重复检测
3. 考虑边界框跨越切片边界的情况

### Q4: 如何处理切片边界上的目标？
A: 可以使用滑动窗口+重叠切片+NMS的方式，详见完整代码。
