## 📈 中期改进（1-2周）

### 1. 实现类别平衡采样

创建新的数据加载器，使用`WeightedRandomSampler`：

```python
# 计算类别权重
class_counts = {
    0: 1,   1: 131,  2: 403,  3: 4781,  4: 1092,  5: 5459,
    6: 1,   7: 5,     8: 0,    9: 14026, 10: 22,   11: 4
}

# 计算采样权重（反向频率）
total_samples = sum(class_counts.values())
class_weights = {
    cid: total_samples / (len(class_counts) * count) 
    if count > 0 else 0
    for cid, count in class_counts.items()
}
```

### 2. 添加Mosaic数据增强

在数据增强管道中添加Mosaic：

```yaml
transforms:
  - type: Mosaic
    input_size: 640
    degrees: 10
    translate: 0.2
    scale: [0.5, 1.5]
  - type: RandomHorizontalFlip
  - type: Resize
    size: [640, 640]
```

### 3. 提升输入分辨率

```yaml
val_dataloader:
  dataset:
    transforms:
      ops:
        - type: Resize
          size: [800, 800]  # 从640改为800
          
eval_spatial_size: [800, 800]
```
